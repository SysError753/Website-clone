# 🌐 Website Clone – HTML & CSS Practice

This project is a **website clone created using only HTML and CSS** for practice and learning purposes.

The main goal of this project was to improve my understanding of **HTML structure, CSS styling, layouts, positioning, Flexbox, spacing, typography, and responsive design** by recreating an existing website interface.

## 🚀 Features

- Built entirely with **HTML5 and CSS3**
- Recreated website layout and UI for practice
- Responsive and structured layout
- Custom styling using CSS
- Practice with:
  - Flexbox
  - Positioning
  - Margins & Padding
  - Typography
  - Colors & Backgrounds
  - Cards and sections
  - Navigation bars
  - Responsive layouts

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**

## 🎯 Purpose

This project was developed as a **frontend practice project** to strengthen my HTML and CSS skills and gain hands-on experience in recreating real-world website designs.

## ⚠️ Disclaimer

This project is created **strictly for educational and practice purposes**. It is a frontend recreation of an existing website design and is not intended for commercial use.
